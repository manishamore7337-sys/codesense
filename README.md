CodeSense AI – Code Explainer

About the Project

CodeSense AI is a Python-based application that helps users understand and analyze Python code using AI.

Features

 Python code analysis
 Syntax error checking
 AI-powered code explanation
 Analysis history stored in a database
 User-friendly interface built with Streamlit

Technologies Used

Python
 Streamlit
 Google Gemini API
 SQLite Database

Project Files

 main.py – Main application
 database.py – Database operations
 .gitignore – Protects sensitive and unnecessary files

Security

API keys are stored in environment variables and should not be uploaded to GitHub.
